# Barclays — Enterprise Agentic AI Platform

At Barclays, I lead an enterprise Agentic AI platform for the Investment Banking division, orchestrating specialised LLM agents via LangGraph to automate regulatory compliance, client onboarding, and knowledge retrieval.

The platform uses GraphRAG on Neo4j, Azure AI, Kubernetes, Docker, and Apache Kafka, with end-to-end security controls across all LLM endpoints.

## Key Contributions

- Designed the end-to-end architecture of a multi-agent Agentic AI platform using LangGraph to orchestrate compliance, onboarding, and knowledge-retrieval agents across the Investment Banking division through stateful, graph-based workflows.

- Implemented tool-calling frameworks within LangGraph, enabling structured tool invocation and context sharing across compliance-checking, document-analysis, and client-profiling LLM agents.

- Built a GraphRAG pipeline using Neo4j knowledge graphs and Azure AI Search, enabling LLM agents to traverse complex regulatory relationships and surface contextually grounded compliance guidance.

- Developed a Copilot experience for compliance analysts using Azure OpenAI Service and LangGraph, providing natural-language, NLP-driven regulatory Q&A grounded in the bank's internal policy corpus through RAG retrieval.

- Deployed the platform on Azure Kubernetes Service using Docker containerisation, Apache Kafka for asynchronous agent-to-agent messaging, and Azure Monitor for real-time observability across all Agentic AI interactions.
